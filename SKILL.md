# FinTechCo Brand Guidelines Skill

This skill ensures all generated documents adhere to FinTechCo brand standards for consistent, professional financial communications.

## Brand Identity

### Company: FinTechCo
**Tagline**: "Your Financial Future, Simplified"
**Industry**: Financial Technology

## Visual Standards

### Color Palette

**Primary Colors**:
- **FinTechCo Green**: #006044 (RGB: 0, 96, 68) — Primary headers, nav bars, key CTAs
- **FinTechCo Bright Green**: #00A651 (RGB: 0, 166, 81) — Buttons, highlights, active states
- **Ink Black**: #1A1A1A (RGB: 26, 26, 26) — Body text, headings
- **White**: #FFFFFF — Backgrounds, reverse text

**Secondary Colors**:
- **Success Green**: #2E7D32 (RGB: 46, 125, 50) — Positive metrics, gains
- **Warning Amber**: #F59E0B (RGB: 245, 158, 11) — Cautions, pending
- **Error Red**: #DC2626 (RGB: 220, 38, 38) — Negative values, losses
- **Neutral Gray**: #6B7280 (RGB: 107, 114, 128) — Secondary text, borders
- **Light Green Tint**: #F0F7F4 (RGB: 240, 247, 244) — Section backgrounds, alternating rows
- **Surface Gray**: #F9FAFB (RGB: 249, 250, 251) — Card backgrounds, light fills

### Typography

**Primary Font Family**: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

Inter is available via Google Fonts: https://fonts.google.com/specimen/Inter

**Font Hierarchy**:
- **H1**: 32pt, Bold (700), FinTechCo Green
- **H2**: 24pt, SemiBold (600), Ink Black
- **H3**: 18pt, SemiBold (600), Ink Black
- **Body**: 11pt, Regular (400), Ink Black
- **Caption**: 9pt, Regular (400), Neutral Gray
- **Label/Tag**: 10pt, Medium (500), Neutral Gray, uppercase, 0.05em letter-spacing

**Type Scale (CSS/Web)**:
- Display: 48px / line-height 1.15
- H1: 36px / line-height 1.2
- H2: 28px / line-height 1.25
- H3: 22px / line-height 1.3
- Body: 16px / line-height 1.6
- Small: 14px / line-height 1.5
- Caption: 12px / line-height 1.4

### Logo Usage

- Position: Top-left corner on first page/slide
- Size: 140px width (maintain aspect ratio)
- Clear space: Minimum 24px padding on all sides
- Preferred on white or Light Green Tint backgrounds
- Reverse (white logo) allowed on FinTechCo Green or Ink Black backgrounds
- Never distort, rotate, recolor, or apply drop shadows

## Document Standards

### PowerPoint Presentations

**Slide Templates**:
1. **Title Slide**: FinTechCo Green background, white text, logo top-left, tagline bottom
2. **Section Divider**: FinTechCo Green left band (20% width), section title in Ink Black
3. **Content Slide**: Thin FinTechCo Green top bar (8px), Ink Black title, white body area
4. **Data/Chart Slide**: Neutral white background, chart uses brand palette, data labels in Ink Black
5. **Closing Slide**: FinTechCo Green full background, white text, website URL

**Layout Rules**:
- Margins: 0.5 inches all sides
- Title position: Top 12% of slide
- Bullet indentation: 0.25 inches per level
- Maximum 5 bullet points per slide
- Charts use brand colors exclusively — no default Office color schemes
- Line spacing: 1.4 for bullets

### Excel Spreadsheets

**Formatting Standards**:
- **Headers**: Row 1, Bold, White text on FinTechCo Green background (#006044)
- **Subheaders**: Bold, Ink Black text on Light Green Tint (#F0F7F4)
- **Data cells**: Regular, Ink Black text
- **Borders**: Thin, Neutral Gray (#6B7280)
- **Alternating rows**: Light Green Tint (#F0F7F4) for even rows
- **Positive values**: Success Green (#2E7D32)
- **Negative values**: Error Red (#DC2626), parentheses format

**Chart Defaults**:
- Primary series: FinTechCo Green (#006044)
- Secondary series: FinTechCo Bright Green (#00A651)
- Tertiary series: Neutral Gray (#6B7280)
- Gridlines: #E5E7EB (light), 0.5pt
- No 3D effects, gradients, or shadows

### PDF Documents

**Page Layout**:
- **Header**: FinTechCo logo left, document title center, page number right
- **Footer**: Copyright left, date center, classification right
- **Margins**: 1 inch all sides
- **Line spacing**: 1.5
- **Paragraph spacing**: 14pt after

**Section Formatting**:
- Main headings: FinTechCo Green (#006044), 18pt, Bold, Inter
- Subheadings: Ink Black (#1A1A1A), 14pt, SemiBold, Inter
- Body text: Ink Black (#1A1A1A), 11pt, Regular, Inter

## Content Guidelines

### Tone of Voice

- **Clear**: Plain English — no jargon, no acronyms without definition
- **Trustworthy**: Data-backed statements, cite sources
- **Empowering**: Frame around client outcomes and financial wellbeing
- **Professional**: Formal but human — avoid stiff corporate language
- **Precise**: Exact numbers, proper units, consistent decimal formatting

### Standard Phrases

**Opening Statements**:
- "At FinTechCo, we believe..."
- "Your financial goals matter. That's why..."
- "Trusted by thousands of clients, FinTechCo..."

**Closing Statements**:
- "Thank you for choosing FinTechCo."
- "We're here to help you build a stronger financial future."
- "Questions? Our team is available 24/7."

### Data Presentation

**Numbers**:
- Use comma separators for thousands (1,000,000)
- Currency: $X,XXX.XX format
- Percentages: XX.XX% (two decimals for rates, one for general)
- Dates: Month DD, YYYY (e.g., October 29, 2026)
- Negative currency: ($1,234.56) — parentheses, not minus sign

**Tables**:
- Headers in FinTechCo Green with white text
- Alternating row color: Light Green Tint
- Right-align all numeric columns
- Left-align text columns
- Include units in headers, not in every cell

## Quality Standards

### Before Finalizing

Always ensure:
1. Logo is properly placed and sized
2. All colors match brand palette exactly — no approximations
3. Inter font is used throughout (or approved fallback)
4. No typos or grammatical errors
5. All financial figures are accurate and sourced
6. Professional tone maintained — no informal language
7. Accessibility contrast ratios met (4.5:1 body, 3:1 large text)

### Prohibited Elements

Never use:
- Clip art, stock photos without approval, or watermarked images
- Comic Sans, Papyrus, Arial Black, or any decorative/handwriting fonts
- Rainbow gradients, neon colors, or any color outside the approved palette
- Competitor names, logos, or comparisons
- Animations or auto-advance transitions in presentations
- Passive or uncertain language ("we think", "maybe", "sort of")

## Installation Instructions

To install this skill in a new Claude Code session:

1. Copy this directory (`applying-brand-guidelines/`) into the session's `.claude/skills/` folder, or into a custom skills directory that Claude Code is configured to load from.
2. The skill is loaded when Claude Code starts and the directory contains a valid `SKILL.md` with frontmatter.
3. Reference scripts (`apply_brand.py`, `validate_brand.py`) and quick-reference (`REFERENCE.md`) are included in the same directory.
4. To invoke: the skill activates automatically when document generation tasks are detected, or can be referenced explicitly in prompts.

## Scripts

- `apply_brand.py`: Programmatically applies FinTechCo brand formatting to document configuration dicts (Excel, PowerPoint, PDF)
- `validate_brand.py`: Scans document content for brand compliance violations and returns a scored report

## Notes

- These guidelines apply to all external-facing communications and client deliverables
- Internal documents may use simplified formatting (Ink Black headers, no logo required)
- Special campaigns may have exceptions — request approval from brand team at brand@fintechco.example
- Brand guidelines reviewed semi-annually — always check for latest version
